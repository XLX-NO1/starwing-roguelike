# 星翼突围

飞机肉鸽游戏首个可玩原型。当前版本是零依赖 Canvas 实现，直接用浏览器即可运行，方便先验证战斗手感、成长循环和数值方向。

## 运行

在项目根目录启动静态服务：

```bash
python3 -m http.server 5173 --bind 127.0.0.1
```

然后打开：

```text
http://127.0.0.1:5173/
```

如果系统没有 `python3`，也可以使用 Codex 自带的 Python：

```bash
/Users/suweichao/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 -m http.server 5173 --bind 127.0.0.1
```

## 操作

- WASD / 方向键：移动
- 鼠标或触控点击：飞向目标点
- Space / Shift：短冲刺
- Q / E / R：释放开局配置的 3 个主动技能，技能有独立冷却时间
- Esc / P：暂停
- 开局前选择难度：简单每次升级选 3 个技能，中等选 2 个，困难选 1 个
- 开局前配置主动技能：推进超载、棱镜护盾、蜂群导弹、时滞力场、奇点炸弹、纳米急救、电磁脉冲、轨道审判
- 战斗中自动射击，升级时从三张强化卡中连续选择本难度对应次数
- 升级技能不封顶，数值强化和武器形态可以持续叠加；弹道/僚机/跳数类技能有软上限，溢出等级会转化为伤害、射速、范围或触发率

## 已实现

- 全屏 Canvas 战斗场景
- 主菜单、HUD、暂停、升级三选一、结算界面
- 开局难度选择：简单 / 中等 / 困难
- 开局主动技能配置，Q / E / R 三键绑定并显示战斗冷却
- 玩家移动、自动索敌、自动射击、受击、护盾、死亡
- 机炮、红色火神炮、蓝色雷射、绿色波刃炮、黄色追踪针、紫电锁链、质子钻光、散射导弹、僚机、电弧等武器/机制
- 追踪、穿梭、炮艇、分裂、装甲、精英敌人
- Boss 深空母舰
- 经验掉落、拾取吸附、升级池、稀有度和难度驱动的升级选择次数
- 粒子、爆炸、命中反馈、伤害数字、屏幕震动
- 无上限时间的完整波次关卡，必须清完当前波敌人才进入下一波
- 每波敌人数已整体提升到原来的 3 倍，并提高同屏敌人/敌弹上限
- 10 个独立关卡，每关都有 12-30 个波次、独立环境配色、环境事件和小 Boss
- 小 Boss 按关卡拥有不同技能组：弹雨、晶体围杀、交叉激光、冰环、冲锋砸地、重力井、裂隙光栅、王牌机动等
- Boss 血量和减伤再次提升，小 Boss 使用更高血量倍率，所有 Boss 承受 20% 实际伤害
- 小怪按关卡成长：每进入下一关，小怪血量变为上一关的 2 倍
- 经验/补给拾取吸附速度提升到原来的 2 倍
- 大地图摄像机视野，战斗区域比屏幕更宽
- 短冲刺、初始护盾和更快的前期升级节奏
- 更多可选技能，覆盖输出、生存、机动、回收和武器专精
- 无上限技能成长优化：高等级采用递减收益、可见实体软上限和溢出强化，后期继续变强但不会无限刷实体拖慢画面
- 酷炫技能效果：轨道激光、黑洞牵引、等离子星环、霜爆突进、击杀星爆、时滞核心
- 新增波中悬赏目标：特定波次会出现高强度精英，击杀后掉落战术芯片
- 新增战术芯片奖励：鹰眼、反应堆、战斗部、回收、相位五类永久小强化，作为关卡内额外构筑来源
- 新增擦弹玩法：贴近敌弹但不被命中可获得连击、得分、少量经验和护盾奖励
- 关卡 HUD 展示当前环境机制，升级卡片和技能栏拥有更清晰的颜色反馈
- 环境玩法：补给舱、陨石穿场、太阳风暴、虚空裂隙增援

## 主要文件

- `index.html`：页面入口和 UI 结构
- `src/styles.css`：界面样式
- `src/data.js`：武器、敌人和常量配置
- `src/content.js`：难度、主动技能、关卡、升级池和稀有度配置
- `src/main.js`：游戏循环、战斗系统、升级执行和渲染
- `DEVELOPMENT_PLAN.md`：完整开发计划
